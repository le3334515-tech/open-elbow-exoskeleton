## 标准型构成

STM32F407VET6 开发板（板载3.3V稳压与SWD）+ Pololu #4692 24V/30:1 37D 电机 + Cytron MD10C Rev3 PWM/DIR 驱动。关节主反馈为3.3V AS5600；电机64CPR编码器是诊断反馈，需5V供电并分压到3.3V。INA240A1 在**电机导线上**做双向电流采样，不放在电源回路冒充电枢电流。5mΩ/10mΩ采样不可混用：首版固定10mΩ、20V/V，输出灵敏度0.2V/A。

动力电源采用外置隔离24V/3A限流直流电源；逻辑5V降压在动力接触器前取电，断开K1时仍保留故障记录。K1为24V线圈、主触点至少30VDC/10A、带NO辅助触点的继电器/接触器；必须按直流额定值选择。急停和两个限位器各用两组独立NC触点：一组串联24V线圈回路，另一组产生3.3V互锁和MCU反馈。

## 启动和复位顺序

1. 上电后监督器和锁存使 `PROTECT_Q=0`，K1未自保持；固件PB0为0，PWM被硬件门控截断。
2. 急停释放、限位均闭合，电流/温度比较器正常后，按物理START。START一组NO触点对保护锁存提供上升沿，另一组NO给K1线圈送电；K1辅助触点自保持。MCU此时仍处待机，电机没有指令。
3. 按台架步骤在零位夹具中校准。主机维持HB，选择低力矩参数后再ARM。
4. 故障时PB0关闭；硬急停/限位/独立过流/温度故障还会异步清除保护锁存并释放K1。
5. 解除故障原因后，需要物理START重新建立硬件锁存，以及按住物理RESET再发送RESET清除固件故障。任何网络指令都不能代替物理START或单独清除实体故障。

`enabled`遥测表示固件输出使能指令，不是接触器闭合证明。首版没有K1焊死检测或接触器辅助触点诊断输入；这些属于扩展验收项目。
