# 机械设计：单肘台架 v0.1

本目录是**原创参数化设计及计算资料**。CAD 已实际导出；实体加工、台架承载、疲劳、温升、佩戴适配均**未执行**。`config/robot.json` 是关节方向、范围、传动与长度的唯一公共参数来源。结构目标为 0.5 Nm 连续、1 Nm/1 s 短时；这些不是硬件实测性能。

## 文件与复现

- `source/build_cad.py`：可编辑 CadQuery 源，局部加工参数集中于 `GEOMETRY`。Python 3.12、CadQuery 2.6.1 已用于本次导出。
- `exports/assembly.step`：带命名零件的装配体；`assembly.stl` 为总装网格。
- `exports/parts/`：48 个实体的逐件 STEP/STL。`M` 开头为原创件，`S` 开头为标准件采购包络。商业带轮、同步带、电机、轴承及传感器包络不代表它们的内部设计。
- `drawings/assembly_isometric.svg`：由实际 CAD 投影导出的等轴图。
- `drawings/key_dimensions.svg`：装配和接口关键尺寸图。
- `exports/cad_validation.json`：实际几何检查结果；`assembly_metadata.json`：名义电机中心和挡块角度。
- `BOM.csv`、`ASSEMBLY.md`、`CALCULATIONS.md`：采购/加工清单、装配步骤、计算与公差。

在仓库根目录执行：

```powershell
python -m pip install cadquery==2.6.1
python mechanical/source/build_cad.py
```

可用 `--angle 0`、`--angle 60`、`--angle 130` 改变总装展示角度；零件 STEP 始终保持共同零位坐标，安装到总装时才应用关节旋转。

## 机械接口

伸直为 0°；从 +Z 看逆时针为正屈肘；上臂沿 −X，前臂在零位沿 +X。软件活动范围 10–120°，固定机械挡块名义 0–130°。20T/60T 开式 HTD 5M 同步带同向传动，外部减速 3:1；电机内部 30:1，总减速 90:1。大带轮转一圈就是关节轴一圈，关节 AS5600 直接读输出轴，不需要再除以 90。

上臂支撑中心距可调 200–320 mm，前臂 180–280 mm，名义 260/240 mm。两个 M5 螺栓通过纵向槽锁定长度；两个袖托底座的横槽提供约 ±7.5 mm 的侧向对齐调整。电机及两个 626 轴承座作为一个整体沿中心线调节 ±5 mm，避免张紧时强迫联轴器偏心。名义中心距 94.648 mm 对应精确开式带几何长度 400.10556 mm；400 mm 皮带需要在槽内微调，不把近似中心距当作加工闭合尺寸。

## 结构与材料

主承力件用 6061-T6 铝；关节轴和中间轴用调质 45 钢或等效材料；挡块与销用钢。12 mm 轴由两只 6001 支承，6 mm 中间轴由两只 626 支承，皮带径向力经中间轴轴承回到框架，避免直接由电机减速器输出轴承担皮带预紧力。电机安装板按 Pololu 4692 的 6×M3、PCD31、轴径6/伸出16 mm 接口建模。

PETG/PA 袖托、护罩及传感器桥可打印做形状和布线验证。**本版所有自制塑料件的强度、层间结合、软垫接触压力和脱离操作均待实体验证**。铝支架和钢轴的 STL 只供可视化或尺寸样件，不能把普通打印件等同于承力金属件。商业 HTD 带轮只建包络，齿形采购，不能从本版 STL 加工齿形。

上臂袖托内半径50 mm、前臂42 mm、轴向宽50 mm，均为成人尺寸的初始假设。配 5–10 mm 可更换软垫和织带；这些不构成适配某一人体的验证结果。快速脱离使用 6 mm 耳叉销＋系留 R 形卡；拔卡后抽销，袖托可与金属侧架分离。织带另设可单手操作插扣。抽销力、受载脱离能力、夹点和活动范围必须在进入佩戴阶段前测量。

## 当前几何证据的边界

拓扑有效不等同于结构强度。已实际检查 48 个正体积 CAD 项；命名的五对承力/护罩零件在 0/60/130° 无体积交叠，挡块在边界相切、越界1°时产生实体干涉。此检查没有覆盖软织带、全部紧固件头部、线束、人体或全部可调尺寸组合；它也不是动力学碰撞或疲劳测试。没有 FEA、加工检验或实体装配记录。
